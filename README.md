# Simple-Neural-Network

A single-neuron neural network built with only NumPy.
It learns the rule "the answer is the first input" from 4 examples.

## How it works
1. Start with random weights
2. Guess using a dot product and sigmoid
3. Measure the error
4. Adjust the weights
5. Repeat 10,000 times

## Run it
pip install -r requirements.txt
python neural_network.py
